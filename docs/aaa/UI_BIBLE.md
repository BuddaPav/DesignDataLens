# UI Bible

## UX Principles

- Игрок всегда видит следующее осмысленное действие.
- Ошибки и ограничения объясняются явно, без silent fail.
- High-contrast и readability важнее декоративных эффектов.

## Visual Language

- HUD визуально связан с фракцией/эпохой через токены, а не hardcoded цвета.
- Иконки и шрифты подчиняются единому scale system.
- Панели в бою/карте/квестах имеют согласованные состояния: loading, empty, error, active.

## Accessibility

- Клавиатурная навигация для всех критичных панелей.
- Минимум базовый WCAG-контраст для основных элементов.
- Тексты и уведомления локализованы, включая error/safety states.

## Localization Contract

- Все новые UI-строки используют i18n keys.
- Запрещены hardcoded тексты в компонентах продукта.
- RU/EN parity обязательна до merge.

## Definition of Done (UI)

- Компонент проходит functional smoke сценарий.
- Нет критичных a11y regressions по внутреннему checklist.
- Документация/скриншоты состояния обновлены в рамках итерации.
