# Chronos MVP — этапы 001–050

**Определение MVP для этого репозитория:** одиночный офлайн-клиент (`app/`), полный цикл интро → персонаж → игра → сохранение/загрузка, процедурные сцены и выборы, базовый социум (NPC, слухи, время), карта 2D/3D с деградацией, панель мира, инвентарь/квесты по доменным правилам, ворота качества `npm run orchestrate:gate`.

Прогресс чекбоксов: `cd app && npm run mvp:progress`.

---

## P0 — Ядро поставки и качество

- [x] **001** Десктоп-сборка Electron + Vite; скрипты `desktop`, `desktop:pack`; запуск `START_DESKTOP.bat`.
- [x] **002** Ворота качества: `npm run orchestrate:gate` (lint + тесты + циклы зависимостей).
- [x] **003** Алиас **`npm run mvp:gate`** = те же ворота (критерий «MVP build healthy»).
- [x] **004** TypeScript-сборка `npm run build` без ошибок типов.
- [x] **005** Vitest: доменные и интеграционные тесты критичных правил (инвентарь, последствия, социум).
- [x] **006** Smoke Playwright `app/scripts/smoke-story.mjs` в CI или документированный ручной прогон перед релизом.
- [x] **007** Версионирование сохранений и миграция при смене схемы (явный `saveVersion` в payload).
- [x] **008** Сохранение: `localStorage` + полный снимок в IndexedDB (`saveSystem`).
- [x] **009** Загрузка мира: восстановление `Map`, NPC singleton, сцена.
- [x] **010** Единый экран «ошибка загрузки» с действием «новая игра / повтор» без молчаливого фейла.

## P1 — Игровой цикл и нарратив

- [x] **011** Фазы: `intro` → `character_creation` → `playing`.
- [x] **012** Генерация сцены, выборы, последствия через `applyChoiceConsequencesBatch`.
- [x] **013** Разделение **`npc_relationship`** и **`quest_unlock`** (нет ложных квестов по id NPC).
- [x] **014** Побочные эффекты батча: дельты отношений, **`npc_mark_dead`**, `markNpcDead` в payload событий.
- [x] **015** Локальная репутация поселения: ключ `location:<id>`, дельты в сценах, домен **`getLocationStanding`**.
- [ ] **016** Минимальный «контентный» проход: N сцен подряд без мягких блокеров (чеклист QA).
- [x] **017** Квесты: генерация + отображение активных/завершённых без дубликатов id.
- [x] **018** Панель квестов: сводка **репутации фракций** (виджет в `QuestPanel`).
- [x] **019** Индикатор **локального standing** текущей локации в панели квестов и/или нижней панели.
- [ ] **020** Сюжетные флаги через `MemorySystem` покрыты smoke-сценарием.

## P2 — Социум, мир, время

- [x] **021** NPC: отношения, память, диалоги (процедурные + опционально WebLLM).
- [x] **022** Слухи: два слоя (контакт + `activeRumors`), worker при тяжёлом тике.
- [x] **023** Караваны и экономика посещений (`traderCaravan`, `caravanEconomy`).
- [x] **024** `factionReputation` и дрейф от охвата слухов.
- [ ] **025** Бой → вызов **`markNpcDead`** для врагов (не только нарратив).
- [x] **026** Коалиции врагов: информативный UI в бою / тултипы — минимум для MVP «понятно, почему враги вместе».
- [x] **027** Панель **«Мир»**: фракции, слухи, журнал, коалиции, фильтры.
- [ ] **028** Баланс дрейфа репутации (плейтест 2–4 ч).
- [x] **029** Пропуск времени «Ждать» с блокировкой сохранения при активном advance.
- [ ] **030** Поколения / полный граф семьи — **не** обязательный для узкого MVP; оставить за скоупом или позже.

## P3 — Карта, навигация, 3D

- [x] **031** Тактическая карта, путешествие, миникарта, компас (по настройкам).
- [x] **032** 3D-мир с пресетами качества и откатом на 2D при ошибке.
- [x] **033** LOD scatter (в т.ч. ultra-far упрощение).
- [x] **034** Стабильный FPS на целевой машине: профилирование и один отчёт `perf-budgets`.
- [x] **035** Внешние GLB: документированный бюджет полигонов на сцену для MVP-контента.

## P4 — Инвентарь, магазин, локализация

- [x] **036** Домен инвентаря: лимиты, стеки, каталог шаблонов.
- [x] **037** Магазин: покупка не ломает инвентарь (граничные кейсы в тестах).
- [x] **038** i18n RU/EN для основного UI и ключевых игровых строк.
- [ ] **039** EN для всех процедурных строк движка — по объёму отложено после узкого MVP.
- [x] **040** Доступность: фокус-ловушки в модалках — базовый аудит (Tab order).

## P5 — ИИ, звук, полировка

- [x] **041** Локальный ИИ: очередь, настройка «только процедурные диалоги».
- [x] **042** Отключение/обработка ошибок WebLLM без падения сцены.
- [x] **043** Звук UI через Web Audio (`SoundManager`).
- [x] **044** Настройки звука сохраняются и применяются после перезапуска (регресс-тест).
- [x] **045** Экран загрузки ассетов / LLM не блокирует навсегда (таймаут с деградацией).
