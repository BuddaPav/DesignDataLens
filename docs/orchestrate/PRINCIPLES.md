# Принципы Orchestrate для Chronos

1. **Правильно, а не быстро** — см. `.cursor/rules/chronos-orchestrate-must-have.mdc`.
2. **Одна истина** — константы и контракты не дублировать (см. раздел 7 в must-have).
3. **Декомпозиция до кода** — scope in/out и три риска для нетривиальных задач.
4. **Долг только явно** — `[TECH_DEBT]` + строка в `TECH_DEBT.md`.
5. **Прототип ≠ продакшен** — см. `plugins/prototype.md`; автоматическое удаление файлов агентом **запрещено**.
6. **Нарратив и механика** — см. `plugins/narrative.md` и чеклист совместимости.
