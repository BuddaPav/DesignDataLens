# Пробелы в автотестах (BACKLOG #45)

Явный список того, что намеренно или пока без покрытия. Обновлять при добавлении крупных подсистем.

| Область | Почему не автоматизировано полностью |
|---------|--------------------------------------|
| Полный нарративный цикл сцен | Зависимость от LLM / недетерминизм процедурных сцен |
| Бой в реальном времени | Нестабильный MVP-слой; smoke по combat-eligibility отдельно |
| IndexedDB сохранения под нагрузкой | Нужен изолированный harness без полного UI (#36) |
| Визуальный регресс 3D | Флаки по GPU/OC; только опциональный скрин по флагу CI (#35) |
| Electron IPC целиком | Интеграционные тесты требуют отдельного runner (#50) |
| Миграции save между версиями | Планируется после стабилизации формата (#42) |

Имеются: юнит-тесты домена (`src/domain/**`), gate (`lint`, `vitest`, `deps:circular`), e2e smoke (`intro-smoke`), путь новой игры (`new-game-flow`), горячие клавиши карты (`map-hotkeys`).
