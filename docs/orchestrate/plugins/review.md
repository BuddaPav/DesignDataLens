# Плагин **review** (код-ревью)

## Цель

Статический анализ и здравый смысл до попадания кода в основную ветку.

## Обязательный минимум

1. `cd app && npm run lint` — без ошибок.  
2. Для домена — `npm run test`.  
3. Ручная проверка: `useEffect` без гонок с Three.js refs; крупные объекты не в замыканиях без нужды.

## Утечки памяти / race (фронт)

- Отписки от `window`, `requestAnimationFrame`, слушателей в cleanup эффектов.  
- Three.js: `dispose()` материалов/геометрий при размонтировании сложных компонентов.

## Сравнение с паттернами проекта

Сверка с существующими модулями (`WorldViewport`, `useGameState`) и с ADR.

## Блокировка merge

В CI (если подключён): job `orchestrate:gate` должен быть зелёным; человеческий аппрув — по процессу команды.
