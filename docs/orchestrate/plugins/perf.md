# Плагин **perf** (performance budgets)

## Цель

Не раздувать клиент и не деградировать кадр без учёта.

## Файл бюджетов

См. `docs/orchestrate/perf-budgets.json` — целевые пороги (ручная проверка / будущий CI).

## Практика в Chronos

- **Бандл:** следить за предупреждениями Viterollup о размере чанков; тяжёлый 3D — lazy `WorldViewport`.  
- **GPU:** лимит `dpr` уже в коде постобработки; не поднимать без замера.  
- **Автобенчмарки:** при изменении горячих путей — профиль Chrome Performance / trace по месту.

## Связь с orchestrate

При приближении к лимитам — задача на оптимизацию **до** добавления новых heavy-фич в тот же модуль.
