# Плагин **rules** (строгие конвенции)

## Цель

Единый стиль, именование, минимум хардкода в доменном слое.

## Реализация

| Инструмент | Что проверяет |
|------------|----------------|
| `.cursor/rules/chronos-code-conventions.mdc` | Именование, `domain/**`, запрет лишнего `any` |
| `eslint.config.js` | TypeScript, React Hooks (настроено под Three.js) |
| `README.md` | Границы продукта Chronos |

## «Блокировка» генерации

Cursor не выполняет код как CI: **агент обязан** следовать правилам из `.cursor/rules/`. При конфликте — править код или явное исключение в ADR.

## Авто-проверка

```bash
cd app && npm run lint
```
