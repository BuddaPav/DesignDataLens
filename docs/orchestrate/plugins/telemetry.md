# Плагин **telemetry** — отладка и метрики

## Встроенный лёгкий профайлер

Модуль: `app/src/debug/chronosTelemetry.ts`.

- Включение в браузере: `localStorage.setItem('chronos_debug_telemetry', '1')` и перезагрузка.
- Функции `traceSync` / `traceAsync` — время выполнения блока (консоль `debug`).
- `profileCalls` — простой счётчик вызовов по ключу.

**Продакшен:** по умолчанию no-op; не логировать PII.

## Логирование состояний для воспроизведения багов

- Для детерминированных систем (инвентарь, квестовое состояние) — при необходимости сериализовать **снимок** в `sessionStorage` только при флаге отладки (отдельный ключ, не включать по умолчанию).
- Не писать полные дампы в прод без согласия и без маскировки.

## Minidump при краше

| Среда | Возможность |
|-------|-------------|
| **Electron** | Можно подключить `crashReporter` в `electron/main.cjs` и политику отправки в отдельной задаче (не включено по умолчанию). |
| **Чистый браузер** | Полноценный minidump как у нативного приложения **недоступен**; используй `window.onerror` / `unhandledrejection` + стек + версия билда. |

Расширение под crashReporter — по отдельному ADR при необходимости.

## Аномалии и код

При обнаружении аномалии (пики времени, счётчики) Orchestrate:

1. Фиксирует метку (`label`) и участок кода.
2. Ищет в репозитории вызовы и горячие пути (grep, deps graph).
3. Предлагает гипотезу и тест/измерение — без «магического» автопоиска причины без контекста.
