# Плагин **autonomous-session** (максимальная автономия в Cursor)

## Цель

Режим длительных сессий: агент **сам** выбирает следующий шаг из **`PROJECT_MILESTONES.md`**, минимизирует уточняющие вопросы, фиксирует архитектурные выборы в коде и в журнале вех.

## Совместимость с Chronos

| Внешняя инструкция | Как в этом репозитории |
|--------------------|-------------------------|
| CORE → SYSTEMS → CONTENT → POLISH | Сопоставлять с фазами в **`PROJECT_MILESTONES.md`** (игровой цикл, движки, контент сцен, полировка). Не подменять **ADR** (`docs/adr/`) и **Orchestrate gate** (`cd app && npm run orchestrate:gate`). |
| `// DECISION: …` в коде | Допускается для **некритичных** развилок; **критичные** решения — по-прежнему **`docs/adr/`** + при необходимости строка в `README.md`. |
| «Без TODO/FIXME» | Не оставлять сырой `TODO`. Отложенная работа — **`// [TECH_DEBT: CHRONOS-TD-NNN] …`** + строка в **`docs/orchestrate/TECH_DEBT.md`** (правило `chronos-orchestrate-must-have.mdc`). |
| «try-catch везде» | **Точечно:** парсинг, сеть, `IndexedDB`, границы Web Worker, внешние API. Не оборачивать горячий рендер React/кадр Three «на всякий случай». |
| `// TOOL UNAVAILABLE` | Если инструмент из запроса недоступен — одна строка в ответе ассистента или в коммите, **без** фейковых результатов поиска/выполнения. |
| «ipython / search_image» | В стеке Chronos по умолчанию не используются; генерация данных — **`app/scripts/*.mjs`**, графика — пайплайн **`asset-pipeline`**, телеметрия — **`telemetry`**. |

## Артефакты

| Файл | Назначение |
|------|------------|
| **`PROJECT_MILESTONES.md`** (корень) | Чеклист фаз, `[x]` / `[ ]`, секция **DECISIONS LOG** (копии значимых `// DECISION` из кода). |
| Этот файл | Контракт плагина и приоритет над общими фразами «режима», если не противоречит **LICENSE**, **ADR** и воротам качества. |

## Практика для агента

1. **Старт сессии** — прочитать **`PROJECT_MILESTONES.md`**, затем `docs/orchestrate/README.md` и релевантные ADR по затрагиваемым путям.
2. **Итерация** — один законченный блок (один модуль, один экран, один доменный пакет + тесты). После зелёного gate — коммит (`feat:` / `fix:` / `docs:` / `chore:`).
3. **После итерации** — отметить `[x]` в **`PROJECT_MILESTONES.md`**, перенести новые **`// DECISION`** в **DECISIONS LOG**.
4. **Коммуникация** (если пользователь явно включил этот режим): кратко `[DONE]` / `[NEXT]`, без опросников; при жёсткой развилке — консервативный выбор + `// DECISION` и запись в лог вех.

## Связь с другими плагинами

- **memory** — ADR остаётся источником истины для спорной архитектуры; вехи — для **очереди** и **сессионного** трекинга.
- **git** — `SYNC_GITHUB.bat` / `scripts/github-push.ps1` после осмысленного коммита.
- **test** + **review** — перед закрытием пункта вехи — `npm run orchestrate:gate` (или согласованное исключение в ADR).
