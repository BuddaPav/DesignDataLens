# Плагин **archaeology** — аудит каждые ~50 коммитов

## Триггер

```bash
cd app && npm run orchestrate:archaeology
```

Если число коммитов в текущей ветке (от корня репо) кратно **50**, скрипт напоминает провести аудит.

## Чеклист аудита

1. **Мёртвый код** — экспорты никуда не импортируются (`deps:export`, grep, IDE unused).
2. **Устаревшие абстракции** — обёртки из одного вызова; кандидаты на слияние.
3. **Дубли констант** — сверка с `domain/**/constants.ts` и принципом одной истины.
4. **Устаревшие ADR** — нужна ли пометка «superseded»?
5. **TECH_DEBT** — открытые строки в `docs/orchestrate/TECH_DEBT.md` соответствуют коду?

## Результат

Краткая заметка в PR или в `docs/orchestrate/` (по договорённости команды) — не обязательно каждый раз новый файл.

Автоматические массовые удаления без ревью **не выполняются**.
