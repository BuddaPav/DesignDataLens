# Плагин **deps** (управление зависимостями)

## Цель

Видеть связи между модулями и избегать циклов.

## Команды (`app/`)

| Скрипт | Назначение |
|--------|------------|
| `npm run deps:circular` | Список циклических импортов (пусто = ок) |
| `npm run deps:export` | JSON-граф в `docs/architecture/module-graph.json` |

## Визуальная карта

- **Mermaid:** `docs/architecture/module-dependencies.mmd` — логические слои (обновляется вручную при архитектурном сдвиге).  
- **JSON:** машиночитаемый полный граф из Madge.

## Impact analysis

Перед изменением публичного типа в `types/game.ts`:

1. Поиск по проекту по имени типа / поля.  
2. `deps:circular` после правок путей импорта.

## Интеграция с orchestrate

Этап **deps** в gate — обязательная проверка отсутствия новых циклов в `src/`.

Примечание: Worker-файлы (`*.worker.ts`) тоже участвуют в анализе импортов; следить, чтобы они не тянули React/UI и оставались на чистой логике.
