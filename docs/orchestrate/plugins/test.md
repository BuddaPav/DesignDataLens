# Плагин **test** (TDD-цикл)

## Цель

Контракт домена закрепляется тестами; регресс ловится на `npm run test`.

## Команды (`app/`)

| Скрипт | Действие |
|--------|----------|
| `npm run test` | Однократный прогон Vitest |
| `npm run test:watch` | Наблюдение при разработке |
| `npm run test:coverage` | Отчёт покрытия в `app/coverage/` |

## TDD для домена

1. Добавить/изменить `src/domain/<area>/*.ts`.
2. Добавить `src/domain/<area>/__tests__/*.test.ts`.
3. Запуск `npm run test` — зелёный до интеграции в React.

## Связь с orchestrate

Задача считается **готовой к merge доменной части** только при зелёных тестах затронутых модулей (в идеале — полный `npm run orchestrate:gate`).
