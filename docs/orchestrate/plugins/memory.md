# Плагин **memory** (расширенный контекст)

## Цель

Сохранять **архитектурные решения** и паттерны между сессиями Cursor и чатами.

## Реализация в репозитории

| Механизм | Назначение |
|----------|------------|
| `docs/adr/` | Формат ADR: контекст → решение → последствия |
| `.cursor/rules/chronos-orchestrate-pipeline.mdc` | Напоминание агенту читать ADR перед крупными изменениями |
| `README.md` (раздел для ИИ) | Конституция продукта — выше частных ADR |

## Практика

1. Спорное решение (новый слой, отказ от паттерна) → новый файл `docs/adr/NNNN-title.md`.
2. В конце работы — одна строка в ADR или обновление «Текущее состояние» в `README.md` при смене поведения.

## Связь с orchestrate

Каждый **модуль** (engine, domain, components) может иметь цепочку ADR; orchestrate перед кодом **читает** релевантные ADR по пути файлов.
