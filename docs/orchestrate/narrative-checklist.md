# Чеклист: narrative beat ↔ механика

Использовать перед merge фичи, затрагивающей сюжет или квесты.

- [ ] Beat описан в типах/данных (флаг квеста, фаза мира, ключ i18n).
- [ ] Вход в beat достижим из текущего состояния (нет блокирующего soft-lock).
- [ ] Выход из beat обновляет единое состояние (одна истина).
- [ ] Строки не дублируются вне `i18n`/согласованного слоя.
- [ ] При удалении/переносе ассета — обновлены ссылки и fallback.
