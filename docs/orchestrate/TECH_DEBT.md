# Реестр технического долга [TECH_DEBT]

Формат в коде:

```ts
// [TECH_DEBT: CHRONOS-TD-001] причина — fix: план или дата
```

| ID | Область | Суть | План закрытия |
|----|---------|------|----------------|
| CHRONOS-TD-001 | `engine/localAI.ts` | Таймаут WebLLM только снимает ожидание UI; загрузка весов в фоне может продолжаться. | Проверить `AbortSignal`/dispose API в `@mlc-ai/web-llm` или изолировать загрузку. |
| CHRONOS-TD-002 | `inheritGrudgeRules` | MVP **077**: покрытие домена юнит-тестами; полная интеграция «NPC узнал о смерти союзника» без автотеста. | Добавить интеграционный сценарий, когда стабилизируется путь событий/NPC tick. |
| — | — | *Добавляй строку при каждом новом TECH_DEBT в коде.* | |

Задача считается незакрытой по Orchestrate, если добавлен новый долг без строки здесь (или без ADR на явное исключение).
