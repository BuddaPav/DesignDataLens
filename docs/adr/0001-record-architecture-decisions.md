# ADR 0001: фиксировать архитектурные решения в репозитории

## Статус

Принято

## Контекст

Проект большой; решения теряются между сессиями ИИ и разработчиков.

## Решение

Ввести каталог `docs/adr/` с нумерацией `NNNN-title.md`. Каждый ADR содержит: контекст, решение, последствия.

## Последствия

- Дополнительное время на документирование.
- Меньше противоречивых рефакторингов и споров о «как было задумано».
