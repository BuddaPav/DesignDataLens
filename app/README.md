# Chronos: AI Chronicles

## 🎮 AI-Powered RPG с бесконечными процедурными историями

**Chronos: AI Chronicles** — это революционная текстовая RPG, использующая передовые алгоритмы ИИ для создания уникальных, адаптивных историй, которые реагируют на ваши выборы, эмоции и стиль игры.

### ✨ Особенности

- **🧠 AI Story Engine** — Процедурная генерация уникальных сюжетов
- **💭 Система памяти** — Игра помнит все ваши выборы
- **🎭 Эмоциональная адаптация** — История меняется под ваше настроение
- **👥 Живые NPC** — Персонажи с уникальными личностями и отношениями
- **🎨 Потрясающая графика** — Частицы, эффекты, плавные анимации
- **🔊 Звуковая система** — Процедурная музыка и звуковые эффекты
- **📱 PWA Ready** — Работает офлайн, устанавливается на телефон
- **⚡ Оптимизация** — 60 FPS на всех устройствах

## 🚀 Развертывание

### Веб-версия

```bash
npm install
npm run build
npm run preview
```

### Google Play Store (Android)

1. **Установите Capacitor**:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init ChronosAI com.chronos.ai --web-dir dist
npx cap add android
```

2. **Соберите проект**:
```bash
npm run build
npx cap sync android
```

3. **Откройте в Android Studio**:
```bash
npx cap open android
```

4. **Создайте релиз**:
   - Build → Generate Signed Bundle/APK
   - Выберите Android App Bundle
   - Создайте или выберите keystore
   - Соберите релизную версию

5. **Загрузите в Play Console**:
   - https://play.google.com/console
   - Создайте приложение
   - Загрузите AAB файл
   - Заполните информацию о приложении

### Apple App Store (iOS)

1. **Установите Capacitor iOS**:
```bash
npm install @capacitor/ios
npx cap add ios
```

2. **Соберите проект**:
```bash
npm run build
npx cap sync ios
```

3. **Откройте в Xcode**:
```bash
npx cap open ios
```

4. **Настройте подпись**:
   - Выберите Team в Signing & Capabilities
   - Укажите Bundle Identifier
   - Настройте Provisioning Profile

5. **Создайте архив**:
   - Product → Archive
   - Distribute App → App Store Connect

6. **Загрузите в App Store Connect**:
   - https://appstoreconnect.apple.com
   - Создайте новое приложение
   - Заполните всю информацию

## 📱 PWA Возможности

Игра полностью поддерживает Progressive Web App:

- ✅ **Офлайн-режим** — Service Worker кэширует все ресурсы
- ✅ **Установка на домашний экран** — Поддержка "Add to Home Screen"
- ✅ **Push-уведомления** — Готовность к уведомлениям
- ✅ **Фоновая синхронизация** — Сохранение данных при восстановлении сети
- ✅ **Адаптивный дизайн** — Работает на всех размерах экрана
