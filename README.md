# Chronos: AI Chronicles

**Полноценная** нарративная RPG: процедурный открытый мир, сцены с выбором и последствиями, NPC с памятью и отношениями, диалоги (процедурный движок и опциональная **локальная** нейросеть на устройстве игрока), 2D-тактическая карта и **GPU**-мир 3D, эпохи, погода, экономика, журнал событий; сохранения в **localStorage** и полный архив мира в **IndexedDB**.

Исполняемый клиент и вся логика — в **`app/`**. Корень репозитория — документация, скрипты запуска Windows, лицензия.

> **Доставка:** основной канал — **установленное приложение** (Electron, отдельное окно, **.exe**). Браузер / PWA — дополнительные режимы. Публичная SEO-страница не цель: `app/index.html`, `app/public/robots.txt` — `noindex`. Для правил разработки и полного контекста см. **[Контекст для ИИ-ассистента](#контекст-для-ии-ассистента)** и код в `app/src`.

## Git и GitHub

Локально уже есть история Git (ветка **`main`**). В `.gitignore` исключены `app/node_modules/`, сборки, `.env`, отчёты Playwright.

**Первый раз — выгрузить на GitHub:** создайте [новый репозиторий](https://github.com/new) (можно без README), затем в корне проекта:

```bash
git remote add origin https://github.com/<ваш-логин>/<имя-репо>.git
git push -u origin main
```

Для HTTPS GitHub попросит **Personal Access Token** вместо пароля ([документация](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)). Альтернатива — **SSH** (`git@github.com:...`) после добавления ключа в аккаунт.

**Обновлять удалённый репозиторий после правок:** запустите **`SYNC_GITHUB.bat`** (или `powershell -NoProfile -File scripts/github-push.ps1`). Скрипт сделает `git add -A`, коммит и `git push`. Свой текст коммита: `powershell -File scripts/github-push.ps1 -Message "feat: кратко"`.

Автоматический пуш «сам по себе» без вашей машины с этой папкой невозможен: GitHub принимает только то, что вы (или CI) отправляете `git push`. Чтобы не забывать, можно повесить **`SYNC_GITHUB.bat`** на расписание в Планировщике заданий Windows — имейте в виду, что тогда коммиты появятся и без ручной проверки диффа.

## Контекст для ИИ-ассистента

> **Для нового чата:** пользователь может написать: «Прочитай раздел для ИИ в README.md и работай» — тогда сначала прочитай этот раздел и продолжай работу с полным контекстом.

### Неоспоримые законы продукта (обязательный ориентир)

Всё ниже — **фиксированные требования** к подходу, текстам и коду; обсуждавшиеся в проекте детали трактуются как **не снимаемые** без явного решения владельца.

1. **Chronos: AI Chronicles** — это **полноценная игра-приложение** уровня **высшего** замысла: **не** «мини-игра», **не** демо и **не** «браузерка». Основной формат поставки — **десктоп** (собственное окно, **.exe**).
2. **Графика** — **лучшая достижимая** в рамках продукта: плотный процедурный мир, постобработка, PBR-окружение, шейдеры, **без** оправдания упрощениями вроде «и так сойдёт».
3. **NPC** ведут себя **как полно разумные** в рамках реализованных систем: **память, знания, психика, отношения, отказ от разговора, реакции на манипуляции**; **локальная нейросеть** (**WebLLM**) — для **ключевых** персонажей, с гибридом и очередями, **без** подмены «одной фразой вместо личности».
4. **Мир** — **детализирован** и **связан**: одни и те же данные **мира** питают 2D-карту и 3D-сцену, биомы, погода, эпоха, **последствия** выборов и поступков отражаются в состоянии мира, NPC и журнале, а не в «тексте ради текста».
5. **README и требования владельца** важнее случайного компромисса ассистента: урезанный функционал, «дешёвая графика» и обесценивание продуктом несовместимы с п. 1–4, если владелец **не** согласовал иное **явно**.

### Идея и зачем этот проект (что нужно владельцу)

**Chronos: AI Chronicles** — нарративная рогалика с **процедурным открытым миром**, **NPC с памятью, психикой, знаниями и отношениями**, **эпохами** (средневековье / современность / будущее) и **гибридом диалогов** (процедурный движок + **локальная** нейросеть **на устройстве игрока** там, где включено и доступно **аппаратно**). **Визуальная планка** — **плотная атмосфера** уровня референсов вроде No Man’s Sky; цель: **максимум качества** в составе **полноценного клиентского** приложения, **без** снятия систем (лор, мир, NPC) ради «просто запустилось».

**Основные назначенные направления работ** (чтобы ответы ИИ и код не расходились с ожиданиями):

| Направление | Суть |
|------------|------|
| **Нарратив** | Сцены с ветвлением, флаги, последствия, привязка к локации/эпохе/погоде, «Продолжить» без кнопок, когда сцена пуста. |
| **Мир** | Большие координаты, те же `worldTiles` для 2D и 3D, путешествия, день/ночь, погода, журнал событий, пропуск времени. |
| **Социум NPC** | Память, отношения, слухи, передача знаний, давление/манипуляции, коалиции врагов (задел), отказы в диалоге при стрессе/ночи/вражде. |
| **Диалоги** | `dialogueSystem` + `knowledge` по эпохе; WebLLM для **ключевых** NPC, процедурный fallback для остальных; кэш и очередь запросов. |
| **Картинка 3D** | Плотный процедурный декор, рельеф с шумом, постобработка, туман, вода, окружение для PBR, без смены лора ради дешёвой графики. |
| **Сборка** | Vite, PWA, Electron, smoke-тесты, i18n RU/EN. |

### Хронология важных изменений (кратко: было → стало)

- **UI / визуал приложения:** единый визуальный стиль «Chronos», панели, интро/загрузка/создание персонажа/игра, шрифты, частицы, настройка «высокое качество графики».  
- **Мир 2D:** `WorldCanvas` — биомы, туман, день/ночь, атлас, **улучшенная «планетарная» отрисовка** (рельеф по тайлу, сетка, сканер).  
- **Мир 3D:** `WorldScene3D` — **сегментация рельефа 256×256**, **simplex**-смещение в вершинах (3 октавы), POM-стиль в фрагменте, мокрость в дождь, **FogExp2** (базовая плотность **0.012** с модификаторами), **PMREM-окружение** (`app/src/rendering/ChronosEnvironment.tsx` + `chronosEnvMap.ts`), `envMap` на instanced-материалах, **подводная/волновая плоскость** (`rendering/WaterSurface.tsx` вместо плоского «океана»), **плавающие острова** (`FloatingIslands.tsx`), **пост-эффекты** (`WorldPostFX`: Bloom threshold 0.1 / intensity **1.2** / radius 0.8, GodRays, шум, хроматика **±0.0015**, контраст/насыщенность, виньетка, ACES, SMAA), **цветные point lights**, молния/вспышка, тени 1024, dpr с потолком 1.5. **Горизонт:** `app/src/world/HorizonHeroLandmarks.tsx` (LOD). **Ресурсы в мире:** `app/src/world/ResourcePickups.tsx` (instanced + **преломление** на кристаллах). **Фауна:** `app/src/entities/WanderingCritters.tsx`. **Диегетичный UI:** `CSS2DRenderer` (`app/src/ui/spatial/Css2DWorldOverlay.tsx`), пузыри над NPC (`NpcCss2DLabels.tsx`), реплики сцены передаются из `GameScreen` в `WorldViewport` как `spatialNpcLines`. Процедурные **составные меши** (`proceduralGeometries.ts`): деревья, скалы, кристаллы, трава, грибы, руины, мезы, sci-fi/город. Старый вариант воды описан в `_archive/world-ocean-plane-deprecated.txt`.  
- **ИИ:** `localAI` — гибрид WebLLM / процедурный, очередь, кэш, системный промпт; настройка «только процедурные диалоги»; CSP/worker для WASM.  
- **Соцлогика:** свидетели, коалиции врагов (частично), память без жёсткой обрезки «как 80 и всё», `psychology` для давления игрока, события/сплетни.  
- **Расширенный социум (2026):** у NPC поле `professionKey` (шаблоны + процедурная толпа); перед тиком поколений заполняются **все пары** отношений в одной локации (`ensureRelationshipPair`); **триады** (общий знакомый сближает пару) и **межлокационные связи по профессии** — `app/src/engine/societySimulation.ts`; процедурная толпа на карте получает те же правила дрейфа (`runCrowdSocietyTick`). **Нарратив и поселения:** в последствиях выбора поддерживается **`locationReputationDelta`** (ключи локаций → дельта к `stats.reputation` с префиксом `location:`), генератор сцен может сочетать её с дельтой фракций; ADR `docs/adr/0005-narrative-location-reputation.md`. **Караваны:** маршрут **`village_ruins_spine`**. **Worker слухов:** пороги **`gossipWorkerRules`**. **Наследие обиды:** `NPCSystem.markNpcDead` + домен `inheritGrudgeRules` (вызов из боя/сюжета — по мере появления). **3D:** второй порог LOD для instanced scatter (`isUltraFar`) — меньше травы/грибов/неона на дистанции.  
- **Рынок слухов и караваны:** в `storyProgress` хранятся `activeRumors` (TTL в игровых часах, охват по графу `connectedLocations`), `tradeCaravans` (маршруты **`willbrook_ring`** и **`ruins_forest_shuttle`**), **`factionReputation`** (дрейф при распространении слухов с `factionTags` — `domain/social/factionReputationRules.ts`, тик в **`advanceTime`** после караванов); логика — `gossipSpreadPure.ts`, `gossipNetwork.ts` (`factionTagsForGossipNpc`), `traderCaravan.ts`; UI — **`WorldStatusPanel`** в `GameScreen`. Документ: `docs/architecture/world-social-graphics.md`.  
- **Графика 3D — пресеты:** тип `WorldGraphicsTier` (`low` / `balanced` / `high`), настройка в панели «Графика» (`worldGraphicsTier` в `chronos_settings`); влияет на **dpr**, плотность тумана, число звёзд/пыли, сегменты воды, силу псевдо-отражения на воде, bloom/god rays/шум/хроматику в `WorldPostFX.tsx`. Туман сцены задаётся только **`SceneFog`** (дублирующий `<fogExp2>` на Canvas убран).  
- **Orchestrate (операционная модель):** `docs/orchestrate/README.md`; обязательные правила — `.cursor/rules/chronos-orchestrate-must-have.mdc` (декомпозиция до кода, `[TECH_DEBT]`, single source of truth, «археолог» каждые ~50 коммитов, принцип «правильно, не быстро»); плагины **scaffold, prototype, telemetry, asset-pipeline, narrative, archaeology** — `docs/orchestrate/plugins/`; реестр долга `docs/orchestrate/TECH_DEBT.md`; шаблоны кода `app/src/scaffolds/`; dev-телеметрия `app/src/debug/chronosTelemetry.ts`; скрипты `npm run orchestrate:archaeology`, `orchestrate:assets`.  
- **Домен инвентаря:** `app/src/domain/inventory/` — `clampGold`, стеки по `tpl:<key>`, **каталог** `itemCatalog.ts` + i18n `item.tpl.*`; ADR `docs/adr/0002-inventory-domain-rules.md`. **Последствия выбора** — батч `app/src/domain/consequences/applyChoiceConsequences.ts` (`item_gain` / `item_loss` / `gold` / прочее) из `useGameState.applyConsequences`.  
- **Прочее:** `.gitignore`, чистка артефактов сборки, i18n-ключи по мере внедрения.

### Протокол качества ответа для ИИ-ассистента («50 опровержений»)

Перед тем как **зафиксировать** рекомендацию, патч или «окончательный» ответ по **каждому** запросу и **каждому** пункту задачи, ассистент **обязан** пройти внутренний цикл самопроверки. Число **50** — не счётчик циклов в чате, а **норма глубины**: идти по чек-листу, пока не исчерпаны существенные возражения. Пока **остаётся** обоснованное «но ведь…», ответ **не** считается исчерпанным. Минимальные оси опровержения (повторять для **каждой** сущности решения: строка кода, пункт ТЗ, формулировка README):

1. **Соответствие идее README и лору** — не ломает заявленный тон, эпохи, механики.  
2. **Альтернатива** — есть ли **другой** хороший путь; почему выбран **этот** (1–2 предложения, без романа).  
3. **Побочные эффекты** — производительность, читаемость, сопровождение, дубли, регрессии.  
4. **Границы** — пустой ли это компромисс, который владелец **явно** запретил.  
5. **Полнота** — **все** подпункты запроса сделаны или **явно** отмечены как вне объёма/требуют данных.  
6. **Документация** — если менялось поведение, **синхронизирован ли** этот README (разделы «Текущее состояние», таблица путей, заделы).  

**Итог в ответе:** при необходимости одна короткая фраза уровня «самокритика: учтены риски X; альтернатива Y отклонена из-за Z» — без раздувания метатекста.

### Суть игры (фактическая реализация в репозитории)

- **Жанр:** нарративная / текстовая RPG с процедурной генерацией сцен и выборов (**Chronos: AI Chronicles**).
- **Главная механика:** чтение сгенерированной сцены → выбор из вариантов → последствия (атрибуты, репутация, флаги, отношения NPC) → следующая сцена; локации на карте, диалоги с NPC, квесты (генерация), автосейв в `localStorage`.
- **Настроение:** тёмный фэнтези-UI (Tailwind, частицы, неон), опционально PWA; язык интерфейса по умолчанию **русский**, переключение RU/EN в настройках (`chronos_settings`).

> **Важно:** исполняемый фронтенд и логика — в **`app/`**. Концепт и замысел — **`CHRONOS_DESIGN.md`** и этот раздел. Файл **`game-design.md`** — заглушка (не описывает текущий продукт). При расхождении любых документов с кодом приоритет у **`app/src`**.

### Текущее состояние

- **Готово:** **полноценное приложение-игра** — **основной** путь: **десктоп** на **Electron** (собственное окно Windows, **.exe**): `npm run desktop` или **`START_DESKTOP.bat`**; для пользователей без Node — **установщик NSIS** **`BUILD_DESKTOP_INSTALLER.bat`** / `npm run desktop:installer` → `desktop-installer/Chronos AI Chronicles-Setup-*.exe`; портативная сборка **`BUILD_DESKTOP_EXE.bat`** / `npm run desktop:pack` → `desktop-dist/ChronosChronicles-win32-x64/ChronosChronicles.exe`. Внутри клиента — **GPU-ускоренный** рендер (шейдеры, пост, IBL). Опционально **генерация сплэш-арта** внешней моделью: `npm run generate:ai-art` при **`OPENAI_API_KEY`**, **`IntroScreen`** читает `generated/manifest.json`. Цикл интро → создание персонажа (**эпоха мира** `character.worldEra`) → `playing`. **Два режима карты мира:** (1) **тактическая 2D-карта** (Canvas) — до **1 000 000 × 1 000 000** тайлов, чанки **50×50**, атлас из `generate-chronos-atlas.mjs`, день/ночь, погода, **рельеф и «сканер»** на тайлах; (2) при **«Высокое качество графики»** — **3D-сцена** (`WorldViewport` → `WorldScene3D`): рельеф, simplex, **туман через `SceneFog`** (модификаторы по погоде/эпохе и **пресету качества**), PMREM, instanced-декор, **вода** с волнами, **псевдо-отражение неба** на воде (сила зависит от пресета), плавающие острова, горизонт с LOD, ресурсы, фауна, **постобработка с пресетами** low/balanced/high (Bloom, GodRays с обнулением нагрузки на low, шум, хроматика, **колористика Hue/Sat по эпохе**, виньетка, ACES, SMAA), **dpr** 1 / 1.5 / 2 по пресету, тени 1024, Chronolith + опциональный GLB; реплики сцены в мире (CSS2D). В **настройках** — переключатель **«Качество 3D-мира»** (низкое / сбалансированное / высокое), сохраняется в `chronos_settings.worldGraphicsTier`. При сбое 3D — откат на **2D** `WorldCanvas`. **Социум:** расширенный граф отношений, толпа на карте в том же социальном тике, **слухи с TTL** и **несколько торговых маршрутов / караванов** при пропуске времени (**«Ждать»**); **`factionReputation`** дрейфует при распространении слухов с `factionTags`; панель **«Мир»** (`WorldStatusPanel`) — репутация, активные слухи, коалиции. **Последствия сцены:** `npc_relationship` применяется к доверию/симпатии NPC (через `ChoiceBatchSideEffects`); смерть NPC — тип **`npc_mark_dead`** или поле **`markNpcDead`** в payload события/квеста → `NPCSystem.markNpcDead` и наследование обиды у союзников погибшего. **NPC:** знания, психика, WebLLM-гибрид, настройка «только процедурные». **Инвентарь:** доменные правила, **каталог шаблонов** `itemCatalog`, последствия `gold` / `item_gain` / `item_loss`. **Сохранения** localStorage + IndexedDB. **Smoke:** `app/scripts/smoke-story.mjs`. Сборка: `cd app && npm run build`.
- **Навигация и карта (игрок):** полноэкранный **оверлей тактической карты** с blur (`WorldTacticalMapOverlay`, **M** / кнопка карты), зум колёсиком, перетаскивание, **ПКМ — вейпоинт** (тост подтверждения), вкладка **«Путешествие»** со списком локаций (`MapPanel`); при **первом** открытии карты — одноразовая строка с подсказкой **M / G / Esc** (`localStorage` флаг `chronos_map_coach_dismissed`); фокус и Tab циклятся внутри оверлея (a11y); **миникарта** в углу (`NavigationMinimap`, настройка в «Игра»); **компас** с маркером ближайшего NPC в мире в 2D-режиме (`NavigationCompassBar`); **G** — краткий **пинг** на текущем тайле (2D + 3D-кольца); данные меток — `localStorage` ключ **`chronos_navigation`** (`navigationStorage.ts`).
- **О графике и референсах (NMS и др.):** ориентир — **визуальная плотность и атмосфера** амбициозных миров; продукт **не** заявляется «урезанной копией» — цель: **лучшая** реализуемая картинка **в составе данного клиента** без отказа от детализации мира. При необходимости **другой** низкоуровневой движок (Godot/Unity/Unreal) — это **эволюция** поставки, **не** оправдание деградации текущего **замысла**.
- **В работе / задел:** UI коалиций врагов в бою с повседневным геймплеем; вызов **`markNpcDead`** из полноценного боя (сейчас — из последствий сцены / нарратива); полный граф поколений; **LOD** instanced-декора при смене чанка и стабильный FPS; отдельные игровые режимы (охота, стройка, ферма) из дизайн-доков; **полный EN** для всего процедурного текста (расширены ключи для **App**, **GameScreen**, **UpdateBanner** и игровых тостов — остаётся процедурный контент движка); **ESLint:** `npm run lint` — **0 errors**, дальнейшая зачистка `exhaustive-deps` там, где это безопасно.

### Важные правила мира (как в коде)

- **Фазы:** `intro` → `character_creation` → `playing` (`useGameState`).
- **Сцена:** `Scene` = narrative + atmosphere + опционально dialogue + массив `choices`; рендер с «печатной машинкой» в `SceneRenderer`.
- **NPC:** у каждого есть `playerRelationship` (trust, affection, …); связи NPC↔NPC хранятся и в глобальной карте, и в `npc.relationships` после синхронизации.
- **Слухи (два слоя):** (1) при разговоре NPC может сдвинуть trust у других в локации и репутацию по ключу локации — заряд события проходит через **«спин» отношений** (`domain/social/npcIndividuality`, `NPCSystem`); враждебный NPC может перевернуть даже нейтрально-положительный контакт в негативный слух; (2) **глобальный рынок слухов** — массив `activeRumors` с TTL и охватом по графу локаций + усиление через **караваны** (`gossipNetwork`, `traderCaravan`); контакт с NPC добавляет на рынок **`buildSocialGossipActiveRumor`**; при распространении слухов с **тегами фракций** дрейф **`factionReputation`** отражается в **журнале мира** (строки из `collectFactionRepShiftLines`). Последствия выбора **`reputation_change`** с ключом ядровой фракции пишут строку через **`formatStoryReputationChoiceLogLine`**.
- **Сохранение:** `chronos_save` в `localStorage`; настройки — `chronos_settings`; звук — `chronos_sound_settings`.
- **Singleton-движки:** `getAIStoryEngine`, `getNPCSystem`, `getMemorySystem`, `getEmotionDetector` — одна инстанция на сессию; при смене архитектуры учитывать порядок импортов (циклы `AIStoryEngine` ↔ `NPCSystem`).

### Как запустить игру и проверить «умных» NPC

1. Запустить **клиент** (предпочтительно **.exe** или `START_DESKTOP.bat`, см. выше).
2. Пройти интро, создать персонажа (включая эпоху), войти в мир.
3. Кликнуть по NPC в сцене или открыть панель «Люди» и выбрать персонажа: сначала появится **процедурный** ответ (знания + память + психика). Если **устройство** поддерживает **WebGPU** и доступна **первая загрузка** весов модели (сеть при первом запуске), тот же блок может **обновиться** ответом **локальной** нейросети **на машине игрока** — без обязательной «облачной» игры.
4. Для проверки экспертизы: поговорить с **Mortimer** в руинах (алхимия), **Thorin** в деревне (военное дело) — в реплике должны фигурировать факты из `knowledge.ts` или отсылка «спроси у …».
5. Кнопка **«Ждать»** в нижней панели продвигает время и наполняет **журнал событий** под шапкой.
6. Сохранение: как раньше, кнопка сохранения; дополнительно полный JSON с `Map` уходит в IndexedDB (имя БД `chronos_idb`).
