# Progress Tracker

## When to use this skill

- Tracking task progress
- Status reporting
- Timeline monitoring
- Completion tracking

## Progress States

| State | Meaning |
|-------|---------|
| pending | Not started |
| in_progress | Currently working |
| completed | Done |
| blocked | Waiting |

## Tracking Methods

- Todo list
- Progress Log
- Obsidian notes
