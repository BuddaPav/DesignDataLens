# Animation Rigger

## When to use this skill

- Skeletal animation
- Animation mixing
- Blend trees

## Animation Types

| Type | Use |
|------|-----|
| Idle | Default state |
| Walk | Movement |
| Run | Fast movement |
| Attack | Combat |
| Death | Death state |
